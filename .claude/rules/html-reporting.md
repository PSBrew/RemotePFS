description: Generate a companion HTML report under ./tmp/ for detailed answers and research
type: reference
---

Produce the normal chat response plus a companion self-contained HTML5 report under `./tmp/`.

- Descriptive `<title>`, executive summary near top, clear section headings.
- Inline CSS, constrained width, monospace code blocks.
- Include a references section when sources are involved.
- Do not replace the chat response with HTML; it is a companion artifact only.
- Do not commit files from `./tmp/`.
